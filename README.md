# 🔍 Análise de Consumo de Energia e Qualidade do Ar com Python

Este projeto realiza uma análise exploratória de dois conjuntos de dados distintos:

1. **Consumo de Energia Elétrica por Região e Classe**
2. **Qualidade do Ar em São Paulo (via API pública)**

Ambos os projetos foram desenvolvidos em Python com visualizações gráficas para apoio na análise de dados.

---

## 📁 Estrutura do Projeto
📦 projeto-analise-dados ┣ 📊 dados_consumo_energia_mensal_por_regiao.csv ┣ 📄 consumo_energia.py ┣ 📄 qualidade_ar.py ┣ 📄 relatorio_projeto.pdf ┣ 🎥 video_pitch.mp4 (link no final) ┗ 📄 README.md

## 🔧 Tecnologias Utilizadas

- Python 3.x
- Pandas
- Matplotlib
- Seaborn
- Requests
- Jupyter Notebook / VS Code

---

## 🧪 Objetivo

- **Parte 1: Consumo de Energia**
  - Analisar o consumo de energia elétrica por região do Brasil.
  - Comparar a evolução do consumo entre diferentes classes de uso (residencial, industrial, etc.).
  - Gerar gráficos de barras e linhas para visualização.

- **Parte 2: Qualidade do Ar**
  - Obter dados em tempo real da qualidade do ar na cidade de São Paulo.
  - Visualizar graficamente os poluentes detectados usando dados obtidos via API da World Air Quality Index (sem autenticação).

---

## 📈 Resultados

Foram gerados diversos gráficos que ajudam a visualizar:

- O total de consumo de energia por região.
- A variação de consumo ao longo do tempo por classe.
- A concentração dos principais poluentes detectados na atmosfera de São Paulo.

## ✅ Conclusão

Este projeto demonstrou como a ciência de dados pode ser aplicada para:

- Compreensão de padrões de consumo energético no Brasil
- Monitoramento de qualidade do ar com dados em tempo real
- Visualização clara para apoio à tomada de decisões
